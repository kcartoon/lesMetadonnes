Les Métadonnées

Qu’est-ce que sont les métadonnées ?

Du grec ancien metá «Au-delà, après»  => Informations, renseignements relatifs à un élément

Présentes dans toutes les données numériques (fichier, mail, page web…) les métadonnées sont les informations qui les caractérisent (Date, propriétaire, expéditeur, lieu, type…).

Elles ne sont pas visibles de prime abord.

A quoi sont-elles associées ?

  • Internet

Ex. Informations contenues dans une page Web (Ce qui permet de la retrouver dans les moteurs de recherches)

  • Applications (Ordinateur, smartphone…)

Ex. Position géographique lors d’envoi d’un courriel, itinéraire emprunté, effort physique réalisé…

  • Fichiers informatiques

Ex. Taille d’une image, créateur du document, dates de création ou de modification, type d’appareil photo, position géographique…
